# フィールド地形タイル AI生成プロンプト（#25 (b)）

ChatGPTで **5枚** 生成 → DL → 下のファイル名にリネームして
`scratchpad/field/` に置く → `node gen_field_art.js` で `src/data/field-art.js` に取り込み → `node build.js`。

- **1枚ずつ生成**（ChatGPTのA/B選択UIが出たら好きな方を選ぶ／1日の画像上限に注意）。
- 全部そろわなくてもOK。**在るタイルだけ差し替わり、無いタイルは今のドット絵のまま**（混在可）。

## 全タイル共通の指定（各プロンプトに含める）
> 真上から見下ろした（トップダウン・真俯瞰）平らな地面のテクスチャを1枚。
> 上下左右の端がつながる**シームレス**（タイル状に並べても継ぎ目が目立たない）。
> 正方形 1:1、遠近感なし、影や光の向きは均一、文字・キャラ・人物・ロゴなし。
> やさしい絵本風／明るいRPG風、コントラスト控えめ、背景は不透明。

---

### 1) t_grass（草原） → `t_grass.png`
> サッカーがテーマの子ども向けRPGのフィールド用、**草原の地面**テクスチャ。
> 明るい黄緑〜緑のやさしい芝生。小さな草の葉や控えめな小花がまばらに散る。
> （＋上の「全タイル共通の指定」）

### 2) t_road（土の道） → `t_road.png`
> **踏み固められた土の道**のテクスチャ。暖かいベージュ〜茶色、小石がほんの少しまばらに。
> （＋共通指定）

### 3) t_wall（石垣・塀） → `t_wall.png`
> 街や小屋のかべになる**石垣（積み石ブロック）／レンガ塀**を真上から見たテクスチャ。
> 灰色〜薄茶の石、継ぎ目はやわらかく。
> （＋共通指定）

### 4) t_water（水） → `t_water.png`
> **澄んだ青緑の水面**テクスチャ。やわらかな波紋、きらめきは控えめ。
> （＋共通指定）

### 5) t_floor（木の床） → `t_floor.png`
> お店の中の**木のフローリング（ウッド床）**テクスチャ。暖色の木目、継ぎ目はやさしく。
> （＋共通指定）

## 取り込み手順（画像が届いたらClaudeが実行）
```
mkdir -p scratchpad/field   # そこに t_grass.png 等を配置
for f in scratchpad/field/t_*.png; do sips -Z 256 "$f" --out "$f"; done   # 任意・容量削減
node scratchpad/gen_field_art.js   # → src/data/field-art.js を生成
node build.js                      # → index.html 再ビルド
```

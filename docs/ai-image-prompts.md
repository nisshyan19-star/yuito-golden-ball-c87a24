# (c) 歩行キャラ（フィールドを歩く5人）

フィールド上を歩く「**ちびキャラ**」。立ち絵とは別物（あれは戦闘用の大きい絵）。
ドラクエ風に **真上やや見下ろし＝トップダウン視点** の小さなキャラを作る。

## ★一貫性のコツ（これが一番大事）
**各キャラの立ち絵を「参照画像」としてChatGPTに添付**してから頼むと、同じ子に見える。
立ち絵は `scratchpad/ally/`（`yuito.png` 等）にある。
添付して →「**この子を、トップダウン視点のRPG歩行ちびキャラにして**」と指示するのが最短。

## 方向は3つだけでOK（左は自動で反転する）
- **正面（down）** … こちらを向いて立つ。顔がしっかり見える。
- **背面（up）** … 後ろ姿（背中・後頭部）。背番号が背中に見えるとなお良い。
- **右向き（side）** … 真横（右を向く）。※**左向きはゲーム側で自動反転**するので作らなくてよい。

→ 5人 × 3方向 = **15枚**。ファイル名は `walk_<英名>_<方向>.png`
（英名: yuito / ikuma / aoshi / tomoki / itsuki、方向: down / up / side）
例) `walk_yuito_down.png`, `walk_yuito_up.png`, `walk_yuito_side.png`

## 全歩行キャラ共通の指定（各プロンプトの末尾に必ず付ける）
> サッカーがテーマの子ども向けRPGのフィールドを歩く、**トップダウン（真上やや見下ろし）視点のちびキャラ**。
> **2頭身のかわいいデフォルメ**、全身がおさまる。**背景は完全に透明（PNG・人物だけ切り抜き）**。
> 影・地面・枠・文字・ロゴは描かない。やさしい絵本風／明るいRPG風、太めの主線、はっきりした色。
> 歩いている静止1コマでOK。1人だけ。

各キャラ、**同じ説明文で down / up / side の3枚**を作る（方向の一文だけ差し替え）。

# (b2) 飾りオブジェ（おまけ・任意）

フィールドに置く小物。**置き場＆描画は実装済み（2026-06-26 #30完了）**。
全6マップに `木/茂み/ゴール/看板/ベンチ/ボール/花` を配置済みで、
**今は「プロシージャル描画（コードで描いたドット/ベクター絵）」で表示中**（実機確認済み）。
固形オブジェ（木/茂み/ゴール/看板/ベンチ）は通行不可、ボール/花は歩ける地面デコール。

**AI画像への差し替えは任意（やりたくなったら、で十分）。**
仕組み＝描画時に **`SRPG.OBJ_ART[key]` があればAI画像、無ければプロシージャル** に自動フォールバック。
差し替え手順：透過PNGを作る → `scratchpad/obj/` に `obj_tree.png` 等で置く → cutout/取り込みで
`OBJ_ART['tree']` 等に登録（`obj-art.js` を新設し末尾に登録IIFE）→ `node build.js`。
**コード変更ゼロで絵だけ差し替わる。** key名：`tree / bush / goal / sign / bench / ball / flower`。
全部 **背景透過PNG**。

### 共通指定（各プロンプトの末尾に）
> トップダウン（真上やや見下ろし）視点のRPG用オブジェクト1個。**背景は完全に透明（PNG）**。
> 影・地面・枠・文字なし。やさしい絵本風／明るいRPG風、太めの主線。サッカーがテーマの世界観。

- **ゴールポスト** → `obj_goal.png`：白いサッカーゴール（ネット付き）。（＋共通指定）
- **サッカーボールの置物** → `obj_ball.png`：白黒のサッカーボールが1個ころんと置いてある。（＋共通指定）
- **木** → `obj_tree.png`：まるい緑の葉の元気な木。（＋共通指定）
- **茂み** → `obj_bush.png`：小さな緑の茂み。（＋共通指定）
- **花畑** → `obj_flower.png`：赤・黄・白の小花のかたまり。（＋共通指定）
- **立て札／看板** → `obj_sign.png`：木の立て札（文字は書かない）。（＋共通指定）
- **ベンチ** → `obj_bench.png`：公園の木のベンチ。（＋共通指定）

# Phase7 新敵10体 AI画像生成プロンプト集（氷の塔＋森の神殿）

げんちゃんがChatGPT等で画像を生成するための台本。
**1体ずつコピペして使う**前提で、各プロンプトは自己完結（共通スタイルを毎回内蔵）。

---

## 使い方（3ステップ）

1. 下の「★共通スタイル」を頭に入れた個別プロンプトを、ChatGPTにそのまま貼る。
2. 生成された絵を **PNG（背景透過がベスト）** でダウンロード。
3. ファイル名は下表の「保存名」で保存してClaudeに渡す → Claudeが `enemy-art.js` に新しいアートキーとして組み込む。

> いまは下表の「流用元アート」を借りて表示中です。新しい絵が入ると、その敵だけ専用の見た目になります（他の敵の絵は変わりません）。

## 組み込み手順（Claude側メモ・げんちゃんが画像をくれたら実行）

1. もらったPNGを `enemy-art.js` に新キーで base64 追加（保存名＝アートキー）。
2. `enemies.js` の各敵の `art:'<流用元>'` を新キーへ差し替え。
   - 例：`snow_yeti` の `art:'stamina_zombie'` → `art:'snow_yeti'`。
3. ボスの怒り絵を入れた場合は、第2形態で `*_rage` に差し替わるよう battle 側を確認（ラスボス dark_kaiser_rage と同じ仕組み）。
4. `node build.js` → `http://localhost:5599/index.html` を実ロードして各敵の戦闘絵を目視＋全テストPASS。
5. md5・バイト数を記録し、memory／Obsidianを更新。

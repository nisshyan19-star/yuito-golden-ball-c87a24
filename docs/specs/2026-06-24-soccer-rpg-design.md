# 設計書：ユイトと黄金のサッカーボール（スマホ向けドラクエ風RPG）

- 作成日: 2026-06-24
- 対象プレイヤー: げんちゃんの息子くん（9歳）想定
- ステータス: 設計承認済み（2026-06-24）→ 実装計画づくりへ

---

## 1. 概要

サッカーをモチーフにしたドラクエ風の小〜中ボリュームRPG。主人公「ユイト」と仲間4人が、悪の組織に奪われた秘宝「黄金のサッカーボール」を取り戻す冒険に出る。ターン制コマンドバトル、レベルアップ、ショップ、セーブを備える。難易度は「やさしい」、9歳が一人でもクリアできてテンポよく遊べることを最優先する。

### ゴール（成功条件）
- スマホのブラウザで開くだけで遊べる（インストール不要・オフライン可）。
- タップ操作だけで完結する。
- 30分前後（中ボリューム）で最後まで遊べる。
- 子供が「クリアできた！」を味わえる、やさしい難易度。

---

## 2. 技術方針

- **単一HTMLファイル**（HTML + CSS + JavaScript をすべて1ファイルに内蔵）。外部ライブラリ・ネット接続なし。
- 描画は **HTML5 Canvas**。ドット絵はコード内のピクセルデータ（文字列配列＋パレット）からプログラムで描画する（プレビューで見せた方式と同じ）。
- セーブは `localStorage`（自動セーブ＋「つづきから」）。
- 操作はすべて**タッチ**。画面下に仮想十字キー＋決定/キャンセルボタン。PCではキーボード（矢印・Enter・Esc）でも動くようにしておくと開発・確認が楽。
- レスポンシブ：縦持ちスマホ基準。Canvasは画面幅に合わせて拡大（`image-rendering: pixelated` でドット感維持）。

### 作り方（採用案）
単一HTMLファイル（Canvas描画）。インストール不要で、AirDrop/ファイル共有で子供にそのまま渡せる。オフラインで動く。

## 3. 世界観・ストーリー

平和なサッカーの国「ピッチランド」。世界に笑顔を生む秘宝「黄金のサッカーボール」が、悪の組織に奪われてしまう。ボールが失われると世界からサッカー（＝楽しさ）が消えていく。少年ユイトは仲間とともに、各地のスタジアムを巡りボールを取り戻す旅に出る。

### ストーリー進行（章＝マップ）
1. はじまりの草原グラウンド（チュートリアル／仲間イクマ加入）
2. ナイタースタジアム（仲間アオシ加入）
3. 砂のグラウンド（仲間トモキ加入）
4. 雨のピッチ（仲間イツキ加入＝5人そろう）
5. 天空スタジアム（中ボス「鉄壁キーパー ガーディアン」）
6. 闇のアリーナ（ラスボス「ダーク・カイザー」→ 黄金のボール奪還・エンディング）

## 4. キャラクター（パーティ）

5人パーティ。**操作するのは主人公ユイトのみ**、仲間4人は「おまかせAI」が自動で行動する（ドラクエの「さくせん」相当）。設定で全員手動に切り替え可能（任意・後回し可）。

ポジション＝バトルでの役割。

| キャラ | ポジション | 役割 | 初期傾向 |
|---|---|---|---|
| ユイト | エース(FW) | バランス型・必殺シュート | こうげき・すばやさ高め |
| イクマ | ストライカー(FW) | 攻撃特化・高火力 | こうげき最高・しゅび低め |
| アオシ | 司令塔(MF) | 全体攻撃・補助 | MP多め・全体技 |
| トモキ | 守りの要(DF) | 防御・かばう | しゅび最高・HP多め |
| イツキ | 守護神(GK) | 回復・立て直し | 回復技・MP多め |

### パラメータ（各キャラ共通の項目）
- HP / MP（MPの呼称は「スタミナ」でもよい）
- こうげき / しゅび / すばやさ
- レベル / 経験値（つぎのレベルまで）
- そうび（ぶき＝スパイク系、ぼうぐ＝ユニフォーム系）

### おまかせAIの行動方針（仲間）
- イツキ：味方のHPが35%以下のキャラがいれば回復、いなければ弱攻撃。
- トモキ：HPが低い味方がいれば「かばう」、いなければ攻撃。
- イクマ：MPが足りれば強い必殺技、足りなければ通常攻撃。
- アオシ：敵が2体以上なら全体技、1体なら単体攻撃か補助。

## 5. 戦闘システム（ターン制コマンドバトル）

- ドラクエ風の見下ろし→エンカウントでバトル画面へ（敵は画面上、コマンドは画面下）。
- 行動順は「すばやさ」順。
- ユイトのコマンド：**たたかう / とくぎ / どうぐ / ぼうぎょ / にげる**。
- 仲間はおまかせAIで自動行動（上記方針）。
- エンカウント：マップ歩行でランダム（やさしくするため頻度は控えめ）＋固定ボス戦。

### ダメージ計算（方針・やさしめ）
- 通常攻撃ダメージ ≒ `こうげき - 相手しゅび/2`（最低1、±10%乱数）。
- とくぎは威力倍率＋属性なしのシンプル設計（属性相性は入れない＝YAGNI）。
- 会心の一撃（たまにダメージ約2倍）でテンポと爽快感を出す。
- 敵から逃げるのはほぼ成功（やさしさ優先）。

### 全滅時（やさしさ設計）
- ゲームオーバーにせず、「直前の町／セーブ地点でHP全回復して再開」。所持ゴールは減らさない（または半分）。子供が詰まらないようにする。

## 8. 育成・経済

- レベルアップ：戦闘で経験値を獲得 → 一定値でレベルアップ、HP/MP/能力上昇＋技習得。やさしくするため必要経験値はゆるやかに。
- 通貨「ゴール」：戦闘・宝箱で入手。
- ショップ（各町に道具屋・装備屋）：
  - どうぐ：スポーツドリンク(HP小回復)、エナジーゼリー(MP回復)、救急バッグ(HP大回復)、リスタートの笛(戦闘不能から復活)
  - そうび：スパイク各種(こうげき↑)、ユニフォーム各種(しゅび↑)
- 宝箱：マップに配置（ゴール・どうぐ・たまに装備）。

## 9. 画面・UI構成

1. **タイトル画面**：「はじめから」「つづきから」。タイトルロゴ＋ドット絵。
2. **フィールド（マップ）画面**：見下ろし型。タイルマップを歩く。下部に仮想十字キー＋メニューボタン。
3. **バトル画面**：上＝敵、中央＝メッセージ窓、左下＝パーティのHP/MP一覧、右下＝コマンド（ユイトのみ）。
4. **メニュー画面**：つよさ（ステータス）／どうぐ／そうび／さくせん（おまかせ⇔手動）／セーブ。
5. **会話・イベント窓**：メッセージウィンドウ（仲間加入・ボス前の会話など）。

UIはドット絵フォント風の枠（ドラクエ風の角丸ウィンドウ）で統一。

## 10. データ構造（概略）

```text
GameState {
  party: [ Character ... ]        // ユイト＋仲間
  inventory: { itemId: 個数 }
  gold: number
  flags: { 仲間加入・ボス撃破・イベント進行 }
  position: { map, x, y }
  settings: { autoAllies: true/false }
}

Character {
  id, name, position(役割), spriteData
  level, exp
  hp, maxHp, mp, maxMp
  atk, def, spd
  skills: [skillId ...]
  equip: { weapon, armor }
}
```

- セーブ：`GameState` を JSON で `localStorage` に保存（オートセーブ＋メニューからセーブ）。

## 11. 難易度設計（やさしい・徹底）

- エンカウント頻度は控えめ。
- 回復アイテムが安く手に入る／回復技が早く使える。
- 全滅してもゲームオーバーにせず復帰（章5参照）。
- ボスは2段階でも全体的にHP・攻撃をやさしめに。
- ヒント表示（次に行く場所を画面やNPCで明示）。

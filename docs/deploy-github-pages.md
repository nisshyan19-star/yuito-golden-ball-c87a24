# スマホで遊べるようにする手順（GitHub Pages・限定公開）

ねらい：息子くんのiPhoneで、URLをタップ → ホーム画面に追加して **アプリみたいに** 遊べるようにする。
検索には出ない（noindex 済み）し、URLを知ってる人しか辿り着けないので、実質「身内だけの限定公開」。

> 公開するファイル：`/Users/gensu/Claud Code/soccer-rpg-yuito/index.html`（1個だけ・6.5MB）

---

## ⚠️ 1点だけ前提
GitHub Pages の無料版は **公開リポジトリ**（＝その気になればソースコードは見られる状態）。
ゲームを遊ぶのには全く関係ないし、検索除け＆URLが分からないと普通の人は辿り着かない。
コードも完全に隠したいなら Netlify 等が向くけど、GitHub で進めるなら気にしなくてOK。

---

## ステップ1：リポジトリ（置き場）を作る
1. ブラウザで https://github.com/new を開く（ログイン済みで）
2. **Repository name** に名前を入れる
   - 例：`yuito-soccer-rpg`（推測されにくくしたいなら末尾に適当な文字を足す → `yuito-soccer-rpg-9f3a2`）
3. **Public** を選んだまま（無料で Pages を使うため）
4. 下の方の緑ボタン **「Create repository」** を押す

## ステップ2：index.html をアップロード
1. 作ったリポジトリの画面で **「uploading an existing file」** のリンクを押す
   （見当たらなければ「Add file」→「Upload files」）
2. Finder で `soccer-rpg-yuito` フォルダを開き、**`index.html` をブラウザにドラッグ＆ドロップ**
3. 下の緑ボタン **「Commit changes」** を押す

## ステップ3：Pages を ON にする
1. リポジトリ上部の **「Settings」** タブ → 左メニューの **「Pages」**
2. **Source** を「Deploy from a branch」
3. **Branch** を `main` ／ フォルダは `/ (root)` → **Save**
4. 1〜3分待つと、同じ画面の上に公開URLが出る：
   `https://（あなたのユーザー名）.github.io/（リポジトリ名）/`

## ステップ4：iPhoneでアプリ化
1. そのURLを **Safari** で開く（同じURLを息子くんのiPhoneにも送る）
2. 下の **共有ボタン**（□に↑）→ **「ホーム画面に追加」**
3. ユイトのアイコンが出る → タップでフルスクリーン起動（アドレスバーも消える＝アプリ感）

---

## 困ったとき
- **URLを開いても真っ白／404**：Pages反映に数分かかる。少し待ってリロード。Branch が `main /(root)` か確認。
- **アイコンがユイトじゃない**：ホーム画面に追加し直す（古いキャッシュのことがある）。
- **コマンドで全部やってほしい**：`gh` CLI を入れて一度ブラウザ認証すれば、リポ作成〜アップ〜Pages設定までこちら（Claude）で進められる。言ってくれればその道に切り替える。

> 公開できてスマホで動いたら、テスト用に立てているローカルサーバ（`192.168.11.18:8765`）は止めるね。
